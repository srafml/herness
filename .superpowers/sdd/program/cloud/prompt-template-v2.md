2. Program pack OUTSIDE the repo: `mkdir -p /tmp/program && git archive origin/program-cloud | tar -x -C /tmp/program`. Every program path below is relative to /tmp/program/.superpowers/sdd/program/. Never commit anything under .superpowers/ on the code branch.
3. Toolchain (lessons from the first cloud run — apply all): `export UV_PYTHON=/usr/bin/python3.12` (python3 may default to 3.11); make sure the pinned uv (see pyproject / uv.lock tooling, 0.11.x) is used — `pip install "uv==0.11.8"` and run it as `python3.12 -m uv` if an older uv shadows it on PATH; the torch wheel host may be blocked by the runner proxy: `uv sync --frozen --no-install-package torch` then `uv pip install torch==<version from uv.lock> --no-deps` from PyPI; `export PYTHONUTF8=1`; `export PYTHON_KEYRING_BACKEND=tests.support.fake_keyring.MemoryKeyring` for the WHOLE session (spawned test children need it); `uv run pre-commit install`. Every commit must pass all commit hooks with NO SKIP and no --no-verify (a hook failure is fixed and re-committed). Never edit a file while a commit's hooks run.
4. Temp files only under /tmp/{GROUP} (never inside the repo). Set TMPDIR=/tmp/{GROUP}.
