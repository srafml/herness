## Loopback client API (from T10-17, binding)
- `herness.core.egress.loopback_http_client(base_url: str, *, timeout_s: float, bearer: SecretStr | None = None, max_response_bytes: int = MAX_RESPONSE_BYTES) -> httpx2.Client` and `aloopback_http_client(...) -> httpx2.AsyncClient` (defined in `herness.core.egress_clients`).
- Sends `Accept-Encoding: identity`; refuses a content-length over the ceiling before reading; counts decoded bytes while the caller reads; over the ceiling raises `EgressBlocked` (`response_too_large`); no redirects; `trust_env=False`; connect timeout `min(timeout_s, 5)`.
- The adapter passes its `MAX_RESPONSE_BYTES` as `max_response_bytes`; its former `OutputValidationError` for oversize bodies becomes `EgressBlocked` — update the tests and the U05-24/U05-26 error rows note accordingly.
