Spec: `docs/impl/02-storage-and-model.impl.md` (T02-19 stage runner, U02-104/U02-110) and `docs/impl/04-metrics-and-scoring.impl.md` (T04-13 run_scoring, U04-56/U04-59).

## Findings (from T04-13, group w22-s04)
1. `stage_score` (herness/model/_build_stages.py) ignores the `yielded` flag in the scoring report, so when `run_scoring` yields (should_yield between steps) the stage reports success, `check` can be skipped and the build can be promoted without its invariants checked. It must return "yield" (StageStatus) when the report flags `yielded`, matching how the enrich stage handles YieldRequested.
2. `build._save_state` / `_yield` (herness/model/build.py ~315-320) rewrite the build state and wipe the scoring checkpoint that `run_scoring` saved via save_checkpoint, so a resumed scoring job restarts from scratch. Preserve the scoring checkpoint across the build's own state save.
